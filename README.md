# freeCodeCamp Python Projects

My solutions to the Python projects from freeCodeCamp's certification.

## Projects

- **project_1.py** - A settings manager that lets you add, update, delete, and view key/value settings stored in a dictionary.
- **project_2.py** - A budget app with a `Category` class for tracking deposits, withdrawals, and transfers between spending categories, plus a function that prints a bar chart of spending by category.
- **project_3.py** - A shape calculator with `Rectangle` and `Square` classes for computing area, perimeter, diagonal, and how many smaller shapes fit inside a bigger one.

More projects will be added here as I finish them.

## Running

Each file is standalone, just run it with Python 3:

```
python project_1.py
```
